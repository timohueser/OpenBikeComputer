# ui

The UI skills are not in the skill listing, so that sessions without UI work do not carry them.
Pick the one skill that fits the task, read its `SKILL.md` with your file tool, and follow it as if
you had invoked it. Relative paths in that file resolve against its own folder.

| Task | Skill |
| --- | --- |
| design, redesign, critique, audit, polish or harden an interface; UX copy, layout, type, colour, accessibility | [impeccable](../../ui/impeccable/SKILL.md) |
| polish of one component's interactions (press, hover, popover, tooltip, drag) | [emil-design-eng](../../ui/emil-design-eng/SKILL.md) |
| build one new animation or transition | [animate](../../ui/animate/SKILL.md) |
| several elements that move together (stagger, sequence, view swap) | [choreograph](../../ui/choreograph/SKILL.md) |
| an animation that drops frames | [animation-performance](../../ui/animation-performance/SKILL.md) |
| review motion in a diff | [review-animations](../../ui/review-animations/SKILL.md) |
| audit and plan motion across the codebase | [improve-animations](../../ui/improve-animations/SKILL.md) |
| find places that should animate | [find-animation-opportunities](../../ui/find-animation-opportunities/SKILL.md) |
| remove motion an interface does not need | [remove-animations](../../ui/remove-animations/SKILL.md) |
