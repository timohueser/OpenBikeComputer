Strong

  • The box cannot be mistaken for an address field: the scope chip is always the first thing in it.
  • The scope chip is also the pointing chip. The four mocks show four scopes: Whole trip, Day 4, End of Day 4, Here.
  • Typed text stays short (“campsites”, “Titisee”), because the scope carries the where.
  • The empty box offers requests for the scope, which teaches what the box can do without a fixed row.

Weak

  • The scope is a mode. If you select Day 4 and forget, “shops” searches only Day 4. The chip shows it, but you must read it.
  • On the trip screen only four or five day rows fit above the Send button.
  • The understood chips do not repeat the scope, so the full request is split between the field and the row under it.
