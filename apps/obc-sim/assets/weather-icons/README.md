# WX17 approved weather icon fixtures

Issue: [#1204](https://github.com/timohueser/OpenBikeComputer/issues/1204)

The owner selected the outlined **Trail** grammar with solid celestial forms and
four detached, staggered diagonal sun glints during the WX17 design review. The
draft PR and issue record pin that art decision; #1204's physical on-glass spot
check remains required before the issue can close. These native `240 x 320`
RGB222 proofs are generated by the ordinary simulator framebuffer from the
production `obc_app::screen::weather_icons` module:

- `wx17-approved-diagonal-glints-family-24px.png` shows every distinct master at
  the hourly-row size on both parchment and HUD backgrounds.
- `wx17-approved-diagonal-glints-dashboard-48px.png` proves that representative
  dashboard icons use the identical masters at exact integer `2x` scale.

Regenerate and review:

```sh
cargo run -p obc-sim --bin weather_icon_sheet
```

Check committed pixels without rewriting them:

```sh
cargo run -p obc-sim --bin weather_icon_sheet -- --check
```
