Built for the long way round

Everything you need to follow a route through the middle of nowhere — and nothing you don't.

Offline vector maps

A whole region in a compact binary format (OBCM), read straight off flash and drawn on-device through an LOD pyramid. No tiles to download, no data plan.

Navigate any route

Drop in a GPX. The device map-matches your position live, shows distance-to-go and a zoomable elevation profile, and trails a breadcrumb behind you.

Records the ride

Tracks ridden distance, moving time, and barometric climb as you go — then exports the whole ride back out as a standard GPX.

One render path

The firmware and this web demo run the exact same Rust drawing code. What you see here is always what the device shows — never a stale screenshot.

Maps a microcontroller can read directly

OpenStreetMap data is packed into OBCM — a self-contained binary map a tiny CPU reads with no JSON, no reparsing, no heap churn. The same Rust core renders it on the desktop and on the device, so the demo above can't drift out of date.

A web map builder lets you pick a region, style it against the device's 64-colour gamut, and build your own map.
