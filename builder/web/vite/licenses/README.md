# Web package license fallbacks

These package releases omit a license file from their npm tarball. The build
uses the matching upstream text only for the exact package version.

| Package | Upstream text |
| --- | --- |
| `pmtiles@4.5.0` | [LICENSE](https://github.com/protomaps/PMTiles/blob/3b10e67edb65c6b04549f74c0279cef8328d859c/LICENSE) |
| `@protomaps/basemaps@5.7.2` | [LICENSE.md](https://github.com/protomaps/basemaps/blob/3ea8293a28131c3dc63f1bb20827bdb8a76df06f/LICENSE.md) |
