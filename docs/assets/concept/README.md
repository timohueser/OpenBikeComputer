# Concept renders

Three WebP files cut from the enclosure colourway sheets. The repository README uses them to show
the hardware direction. The sheets themselves are not in the repository, so these files cannot be
rebuilt from it — keep the sheets if you want to re-cut.

| File | Content |
| --- | --- |
| `front.webp` | The Forest sheet's large render, cropped to the studio panel. |
| `dash.webp` | The Forest sheet's `DASH` thumbnail, the same device at three quarters. |
| `colorways.webp` | All five `DASH` thumbnails, composed into one grid. |

Each crop stops inside the panel's rounded corners, so no corner of the page background survives.
On a 1200 × 1534 sheet the large render is `(110, 154)` to `(1090, 938)` and the `DASH` thumbnail is
`(92, 1216)` to `(416, 1442)`.

`colorways.webp` is composed, not cropped: five rounded cards, three over two, on a **transparent**
background so the grid reads on the light and the dark GitHub theme. Each card carries its
thumbnail above a label strip filled with the colour of the thumbnail's own bottom edge, which hides
the join. The strip holds the colourway name, the accent name, and the two colours as chips.

| Colourway | Body | Accent |
| --- | --- | --- |
| Petrol / Aqua | `#29465C` | `#3AD3E2` |
| Forest / Celadon | `#488781` | `#8BE3BC` |
| Wine / Coral | `#693744` | `#FF8B77` |
| Aubergine / Lilac | `#4D3C77` | `#D9D0F5` |
| Stealth / Graphite | `#1F252C` | `#465059` |

These are concepts, not the agreed design. Replace them when the enclosure is decided.
