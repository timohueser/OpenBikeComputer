## how_it_works
Decisions live in three layers: the epic body (#1449, whose 2026-09-13 status table explicitly "supersedes old task forecasts and unchecked historical lists below"), owner comments on children, and the three binding docs (CLAUDE.md = AGENTS.md verbatim, CONTRIBUTING.md, docs/testing.md). The registry (testing/suites.toml) is the executable form of the policy; tools/suite_registry.py is the single selector; ci.yml's `selection` job consumes its plan (docs/testing.md:218-222).

- The 2026-06 audit (#90) found the Rust tests genuinely protective (exact bytes/pixels/distances, per-test rationale), so 'reuse, don't rewrite' (owner requirement 1) is backed by evidence, not hope.
- Native result artifacts now exist for Rust (4,163 identities), web (1,511+7) and Swift Testing (567) with zero extra test execution — the raw material for on-demand timing analysis is already in CI.
