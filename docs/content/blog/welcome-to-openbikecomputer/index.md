Hello and welcome to what is hopefully the first of many small technical writeups and blog posts about the OpenBikeComputer project. The idea here is to try and share some of the things that I learn along the way, and write some tutorials on things that I did not find any good ones already on the internet.

Now let's get one thing out of the way first. All the code in this project is written using agentic AI tools. I know, I know, you're tired of hearing about it, so am I! So I promise this will not be another "It's so OVER - look what Claude built in just 5 minutes" kind of affair. But I think these tools fundamentally change the way we work, and shift the main challenges of hobby projects like this from being able to write good code, to having good ideas, and making the right big-picture decisions about what you're trying to build. This also means that these blog posts won't always be in-depth coding tutorials, but instead focus on the broader concepts. I will make sure to include code snippets and working examples wherever possible, but I think in this brave new world we live in concepts matter much more than detailed implementation. Whether you love it or hate it, you can probably throw this blog post at Claude or Codex and they'll build the system I'll describe for you in minutes.

Also one last promise and then I'll shut up and get to the point: Not a single line of text you will read in this blog will ever be generated by AI, this is written by human(s) for humans and I will do my best to make this statement true for every single line of text anywhere else in the project too, but that will take some time.
