# BOM and schematics

The main board and USB daughterboard are in development. These exports describe
the current design. They are not a complete production hardware release.

The published table, CSV files and schematic PDFs come from the KiCad projects
on `develop`. Hardware changes update them when the site build completes.
Component fields in the schematics are the source for specifications and prices.
See the [hardware README](src:hardware/README.md) to edit fields or make local exports.

Prices are in EUR, excluding VAT. They use recorded supplier quotes for builds
of 10 and 1,000 complete devices. Quote dates appear in the table. The CSV files
also contain component review notes. Check prices, stock and delivery before you order.
