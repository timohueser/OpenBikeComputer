# Ride Assistant mocks (temporary branch)

This branch holds the mocks for the Ride Assistant plan in the GitHub issue that links here. It is not
part of develop. Delete the branch when the work moves into pull requests.

- `mocks/`: device frames at 240 × 320, drawn twice as large, with the firmware's Terminus fonts.
- `prototype/index.html`: the interactive prototype. Download it and open it in a browser. The keys
  under the screen, or ↑ ↓ Enter Esc, drive it; H opens Help.

Map data © OpenStreetMap contributors. Heights contain modified Copernicus data.
